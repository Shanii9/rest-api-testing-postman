# REST API Testing Portfolio
## Project Overview

This project demonstrates hands-on REST API testing using Postman and the JSONPlaceholder API. It includes positive and negative testing, CRUD operations, query parameters, collection variables, response validation, headers, response-time checks, and automated Postman assertions.
## What I Tested

- GET requests for single and multiple resources
- POST requests with valid and incomplete data
- PUT requests for full resource updates
- PATCH requests for partial updates
- DELETE requests
- Positive and negative API testing
- Query parameter filtering
- HTTP status code validation
- JSON response validation
- Response header validation
- Response time validation
- Postman automated assertions
- Collection variables using `{{base_url}}`

## How to Run This Project

1. Download or clone this repository.
2. Open Postman.
3. Import `REST API Testing Portfolio.postman_collection.json`.
4. Open the imported collection.
5. Set the collection variable `base_url` to:

   `https://jsonplaceholder.typicode.com`

6. Run individual requests or use the Collection Runner.
7. Review the automated assertion results in Postman.

## API Used

This project uses the JSONPlaceholder REST API, a public fake API designed for testing and prototyping.

Base URL:

`https://jsonplaceholder.typicode.com`
